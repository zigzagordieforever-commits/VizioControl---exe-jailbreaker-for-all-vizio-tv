# Changelog

## 1.7.2-rc1 — Pairing / HTTP 403 release candidate

- Added a SmartCast PIN pairing action.
- Saves the AUTH token in the local VizioControl profile and reuses it for supported requests.
- Adds a clearer message when the TV says a request needs pairing.
- Keeps the App Maker and SmartCast Sender from earlier builds.
- Includes the separate screen-mirror cursor overlay from the current source.

## 1.7.0 — App Maker

- Added starter layouts for TV-friendly web apps.
- Added app editing, preview, launch, and web-project export.
- Clarified that a hosted Conjure page is not a permanent native SmartCast install.

## 1.6.x — Developer and network tools

- Added SmartCast request testing and DNS Sender tools.
- Added DNS forwarding improvements and more network diagnostics.
